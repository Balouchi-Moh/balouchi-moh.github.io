# راهنمای سایت محمد بلوچی — نسخه‌ی بازطراحی‌شده ۲۰۲۶

## ۰) چه چیزهایی عوض شده؟ (نسخه‌ی جدید)
ظاهر سایت کاملاً بازطراحی شده — تم تیره‌ی لوکس با اکسنت کهربایی و بافت «شبکه‌ی نقشه‌کشی» — اما **ساختار فایل‌ها دقیقاً همان ساختار قبلی است** و هیچ نرم‌افزار یا نصبی لازم ندارد؛ مثل قبل روی GitHub Pages یا هر هاستی آپلود می‌شود.

چیزی که جدید اضافه شده:
- انیمیشن ورود بخش‌ها هنگام اسکرول، شمارنده‌های متحرک آمار، نمودار گانت متحرک
- نوار متحرک (marquee) زیر صفحه‌ی اول، نورافکن روی کارت‌ها، افکت بزرگ‌نمایی عکس پروژه‌ها
- فونت Space Grotesk برای نسخه‌ی انگلیسی + فونت وزیرمتن برای فارسی (هردو داخل سایت — به اینترنت وابسته نیست)
- **عکس‌های واقعی پروژه‌ها** (ایران‌مال، سد تبارک‌آباد، سد کمندان، کرمانشاه، اندیشه، تجاری-اداری) — از سایت قبلی حفظ شده‌اند
- دکمه‌ی «دانلود / چاپ رزومه» در صفحه‌ی رزومه اکنون نسخه‌ی چاپی تمیز (سیاه‌وسفید) می‌سازد

## ۰-۱) رایج‌ترین تغییرهایی که ممکن است بخواهی بدهی
| می‌خواهم... | کدام فایل را باز کنم | چه چیزی را تغییر بدهم |
|---|---|---|
| عکس یا نقش یک پروژه را عوض کنم | `data/projects.json` | عنوان/نقش/آدرس عکس هر پروژه (عکس جدید را در `images/projects/` بگذار) |
| مقاله اضافه یا ویرایش کنم | `data/posts.json` + فایل جدید در `blog/` | یک آبجکت جدید به آرایه‌ی posts اضافه کن (راهنمای داخل خود فایل هست) |
| شماره‌های آمار (۲۰+، ۱۵+، ...) را عوض کنم | `index.html` | عدد داخل `data-count="20"` و متن داخل `<b>` هر دو را عوض کن |
| متن‌های صفحه‌ی اول را عوض کنم | `index.html` | هر متن مستقیم داخل فایل هست |
| رنگ کهربایی را عوض کنم | `css/style.css` | خط ۲۵ تا ۲۸ (`--amber: #f2b33d`) |
| کلمه‌های نوار متحرک را عوض کنم | `index.html` | بخش `<div class="marquee">` (دو بار تکرار شده — هر دو را عوض کن) |
| آدرس‌ها و شماره تماس | `contact.html` + فوتر همه‌ی صفحات | متن‌های `footer-bottom` و بخش راه‌های ارتباطی |

قاعده‌ی کلی: **متن‌ها در فایل‌های HTML، لیست پروژه‌ها و مقالات در `data/*.json`، و همه‌ی ظاهر و رنگ‌ها در `css/style.css` است.**

## ۱) پیش از انتشار — چند مورد را تکمیل کن
- در فایل `contact.html`، لینک لینکدین و صفحه دانشگاهی را جایگزین `#` کن.
- در فایل `contact.html`، به جای `YOUR_FORM_ID` یک فرم رایگان در https://formspree.io بساز (چند دقیقه طول می‌کشد، بدون نیاز به سرور، ایمیل فرم مستقیم به اینباکس تو می‌رسد).
- در فایل‌های `robots.txt` و `sitemap.xml`، `YOUR-DOMAIN.example` را با آدرس نهایی سایتت جایگزین کن.
- درباره‌ی «کارشناس رسمی دادگستری»: فعلاً این عنوان در سایت درج نشده. اگر مایلی اضافه شود، رشته و شماره پروانه را به من بگو تا در صفحه‌ی خدمات (بخش ۰۶) دقیق اضافه‌اش کنم.

## ۲) انتشار رایگان با GitHub Pages (پیشنهاد اصلی)
1. یک حساب رایگان در https://github.com بساز (اگر نداری).
2. یک ریپازیتوری جدید بساز، مثلاً به نام `mysite` (Public).
3. تمام فایل‌های همین پوشه (site) را در آن ریپازیتوری آپلود کن (دکمه‌ی «Add file → Upload files» در گیت‌هاب، کشیدن و رها کردن فایل‌ها کافیست).
4. به تنظیمات ریپازیتوری برو: **Settings → Pages**.
5. زیر «Build and deployment»، گزینه‌ی Source را روی **Deploy from a branch** بگذار، Branch را `main` و پوشه را `/root` انتخاب کن، سپس Save بزن.
6. بعد از ۱-۲ دقیقه، آدرس سایتت این شکلی فعال می‌شود:
   `https://USERNAME.github.io/mysite/`

اگر بخوای دامنه‌ی اختصاصی خودت (مثل mohammadbalouchi.com) روی همین هاست رایگان بیاد، در همان صفحه‌ی Settings → Pages بخش «Custom domain» را هم می‌توان تنظیم کرد؛ فقط دامنه باید جداگانه (با هزینه کم سالانه) خریداری شود.

### جایگزین: Cloudflare Pages
اگر خواستی روش دیگری هم امتحان کنی: در https://pages.cloudflare.com حساب بساز، پوشه‌ی سایت را مستقیم Drag & Drop کن؛ ظرف چند ثانیه آدرس رایگان می‌گیری. سریع‌تر از GitHub Pages ولی گیت‌هاب برای یادگیری بلندمدت مفیدتر است.

## ۳) بالا آمدن در گوگل (سئوی پایه)
سایت از همین حالا این موارد سئو را دارد:
- عنوان و توضیح اختصاصی (meta title/description) برای هر صفحه
- ساختار عنوان‌بندی درست (h1 → h2)
- فایل `sitemap.xml` و `robots.txt`

برای دیده‌شدن در نتایج گوگل:
1. بعد از انتشار سایت، به https://search.google.com/search-console برو و سایتت را با ایمیل جیمیلت اضافه کن.
2. آدرس `sitemap.xml` را در Search Console ثبت کن (مثلاً `https://USERNAME.github.io/mysite/sitemap.xml`).
3. صبر کن؛ معمولاً چند روز تا چند هفته طول می‌کشد تا گوگل صفحات را ایندکس کند.
4. برای نتیجه سریع‌تر: لینک سایتت را در پروفایل لینکدین، پست‌های لینکدین/اینستاگرام حرفه‌ای، و امضای ایمیلت بگذار — لینک از منابع معتبر، رتبه در گوگل را بالا می‌برد.
5. مقالات وبلاگ را مرتب (مثلاً ماهی یک بار) اضافه کن؛ محتوای تخصصی و به‌روز، مهم‌ترین عامل بالا آمدن در جستجوهای «مشاور مدیریت ساخت» یا «ساخت‌وساز ناب» است.

## ۴) ویرایش‌های آینده
هر متن یا بخش سایت را می‌توان مستقیم در فایل‌های html ویرایش کرد (همه با ادیتور ساده مثل Notepad یا VS Code قابل باز شدن هستند)، یا هر زمان خواستی، از من بخواه تغییرش بدهم.
