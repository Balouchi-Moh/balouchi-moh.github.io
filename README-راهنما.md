# راهنمای سایت lean-construction.ir — نسخه ۲ (سه‌زبانه)

## چه چیزی عوض شد؟

- **زبان پیش‌فرض سایت انگلیسی است** و در ریشه قرار دارد: `lean-construction.ir`
- **فارسی** در پوشه `fa/` → `lean-construction.ir/fa/`
- **عربی** در پوشه `ar/` → `lean-construction.ir/ar/`
- در هدر همه صفحات یک **سوییچر زبان (EN | فا | ع)** هست که بین معادلِ همان صفحه در زبان دیگر جابه‌جا می‌شود.
- اگر زبان مرورگر بازدیدکننده فارسی یا عربی باشد، یک نوار کوچک بالای صفحه پیشنهاد می‌دهد نسخه همان زبان را ببیند (یک‌بار قابل بستن است).
- ظاهر سایت همان هویت «بلوپرینت تیره + کهربایی» قبلی است، ولی سر‌تا‌سر بازطراحی و ارتقا داده شده: هیرو مهندسی با قاب نقشه، نوار اعتماد (کیسون، ایران‌مال و...)، نمودار گانت اصلاح‌شده، فرم تماس، دکمه واتس‌اپ و لینکدین.
- لینک‌های قدیمی `/en/...` به‌صورت خودکار به صفحه جدید هدایت می‌شوند (فایل‌های استاب در پوشه `en/`).
- تگ‌های `hreflang` و `sitemap.xml` برای گوگل به‌روز شده‌اند.

## انتشار روی GitHub Pages (مثل قبل)

کافی است محتویات همین پوشه را جایگزین کل فایل‌های ریپوی `balouchi-moh.github.io` کنید:

**روش ۱ — از مرورگر (ساده‌ترین):**

1. وارد ریپو شوید → دکمه «Add file» → «Upload files»
2. همه فایل‌های این پوشه را بکشید و رها کنید (فایل‌های هم‌نام جایگزین می‌شوند)
3. پایین صفحه پیام کامیت بنویسید (مثلاً «نسخه ۲ سه‌زبانه») → «Commit changes»
4. ۱ تا ۲ دقیقه بعد سایت به‌روز می‌شود؛ برای دیدن نسخه جدید صفحه را با Ctrl+Shift+R (بدون کش) باز کنید

**روش ۲ — با خط فرمان:**

```bash
cd balouchi-moh.github.io
# فایل‌های جدید را داخل ریپو کپی کنید (جایگزین قبلی‌ها)
git add -A && git commit -m "v2: trilingual redesign (EN default + FA + AR)"
git push
```

> **نکته مهم:** فایل‌های `CNAME`، `google1c3fe492fcfeaf02.html`، `.nojekyll` و پوشه `.github/` را حذف نکنید — دامنه، تأیید گوگل و اتوماسیون‌ها به آن‌ها وابسته‌اند.

## پیش‌نمایش روی کامپیوتر خودتان

```bash
cd lean-construction-v2
python3 -m http.server 8000
```

بعد در مرورگر: `http://localhost:8000`

(باز کردن مستقیم فایل html بدون سرور، بخش‌های داینامیک پروژه‌ها/مقالات را نشان نمی‌دهد — حتماً از سرور محلی استفاده کنید)

## ساختار فایل‌ها

```
/                    ← انگلیسی (پیش‌فرض): index, services, resume, contact, blog/
/fa/                 ← فارسی: همان صفحات + blog/
/ar/                 ← عربی: صفحات اصلی + blog/ (مقالات فعلاً به نسخه انگلیسی لینک می‌شوند)
/blog/               ← مقالات انگلیسی
/fa/blog/            ← مقالات فارسی
css/  js/  fonts/    ← مشترک بین هر سه زبان
data/projects.json   ← پروژه‌های نمایشی (سه‌زبانه)
data/posts.json      ← لیست مقالات (سه‌زبانه)
en/                  ← فقط ریدایرکت‌های لینک‌های قدیمی
```

## افزودن مقاله یا پروژه جدید

**مقاله فارسی:** فایل `fa/blog/نام-مقاله.html` را بسازید (از مقاله‌های فعلی همان پوشه الگو بگیرید) و در `data/posts.json` یک آبجکت جدید با فیلدهای `title_fa`، `excerpt_fa`، `tag_fa` و `link_fa` (به شکل `fa/blog/نام-فایل.html`) اضافه کنید. مقاله انگلیسی هم به همین شکل با فیلدهای `*_en` و فایل در `blog/`. فیلدهای `*_ar` را هم می‌توانید همین حالا پر کنید تا در نسخه عربی هم نمایش داده شود.

**پروژه جدید:** فقط `data/projects.json` را ویرایش کنید (عکس در `images/projects/`).

## اتوماسیون‌ها (GitHub Actions)

- **Daily AI Agent** موقتاً غیرفعال شد (کرن حذف شد؛ اجرای دستی از تب Actions ممکن است). علت: خروجی ربات برای ساختار قدیمی سایت بود و با ساختار سه‌زبانه هماهنگ نیست؛ ضمن اینکه انتشار خودکارِ محتوای تولیدی AI روی سایت حرفه‌ای ریسک اعتباری دارد. اگر خواستید فعالش کنید در `.github/workflows/daily-agent.yml` خط cron را برگردانید — ولی بهتر است اول مسیر خروجی‌اش به ساختار جدید اصلاح شود.
- **Weekly Content Draft** دست‌نخورده است: هر دوشنبه یک پیش‌نویس به‌صورت Pull Request می‌سازد و فقط با تأیید خودتان منتشر می‌شود. توجه: مقاله‌ای که merge می‌کنید در مسیر قدیمی ذخیره می‌شود؛ بعد از merge فایل را به `fa/blog/` منتقل و در `posts.json` ثبت کنید (یا موقتاً این ورک‌فلو را هم از تب Actions غیرفعال کنید).

## سئو

- هر صفحه سه نسخه با آدرس مستقل دارد + تگ‌های `hreflang` (شامل `x-default` → نسخه انگلیسی)
- `sitemap.xml` هر سه زبان را با معادل‌هایشان معرفی می‌کند
- لینک‌های قدیمی `/en/...` با ریدایرکت استاب منتقل می‌شوند؛ آدرس‌های فارسی قدیمی (مثل `services.html`) اکنون همان صفحه انگلیسی را نشان می‌دهند — گوگل به‌تدریج با کمک hreflang ایندکس‌ها را به‌روز می‌کند و سوییچر + نوار پیشنهاد زبان، بازدیدکننده فارسی‌زبان را راهنمایی می‌کند
