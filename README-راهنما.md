# راهنمای سایت — lean-construction.ir

## ظاهر سایت
یک تم واحد و ساده در کل سایت: **پیش‌فرض انگلیسی، پس‌زمینه سفید، آبی (#2563eb) و مشکی/سرمه‌ای (#0f172a)**.
تم تیره‌ی قبلی («وبلاگی») به‌طور کامل حذف شده و همه‌ی صفحات — از جمله مقالات بلاگ — از همان ظاهر ساده استفاده می‌کنند.

## ساختار
```
index.html            صفحه اصلی (انگلیسی — پیش‌فرض)
services.html         خدمات (انگلیسی)
resume.html           رزومه مشاور (انگلیسی)
contact.html          تماس (انگلیسی)
blog/index.html       فهرست مقالات (انگلیسی → نسخه‌های en/blog)
en/                   نسخه کامل انگلیسی سایت
fa/                   نسخه فارسی (صفحه اصلی + خدمات + رزومه مشاور + مقالات + تماس)
ar/                   نسخه عربی
blog/*.html           متن کامل مقالات فارسی
en/blog/*.html        متن کامل مقالات انگلیسی
articles/*.html       مقالات هفتگی تولیدشده توسط agent.py
css/style.css         تم روشنِ ساده (فقط یکی، برای کل سایت)
js/main.js            منوی موبایل + انیمیشن ظاهرشدن + بارگذاری پروژه/مقالات از data/*.json
data/posts.json       فهرست مقالات (نمایش در en و fa)
data/projects.json    فهرست پروژه‌ها
scripts/generate_weekly_post.py + scripts/templates/  تولید مقاله هفتگی
```

## تغییرات این نسخه (خلاصه)
1. **تم ساده در کل سایت** — `css/style.css` کاملاً بازنویسی شد: سفید/آبی/مشکی، بدون تم تیره. صفحات `en/`، مقالات بلاگ (فارسی و انگلیسی) و `articles/` هم‌اکنون همان ظاهر ساده را دارند.
2. **متن صفحه اصلی** — به‌جای عنوان «Ph.D. …»، صفحه اصلی (انگلیسی و فارسی) معرفی **خدمات مدیریت ساخت و ساخت‌وساز ناب** است.
3. **تب رزومه** — «PhD Resume» → «Consultant Resume» (انگلیسی) و «رزومه مشاور» (فارسی/عربی) در همه‌ی صفحات.
4. **رفع باگ‌ها** — صفحه `fa/index.html` که کپی رزومه بود به صفحه اصلی فارسی تبدیل شد؛ مسیر CSS خراب `articles/post-*.html` اصلاح شد؛ جهت `rtl` آن مقالات درست شد؛ لینک‌های خراب بلاگ (fa و ar) اصلاح و `fa/blog/index.html` اضافه شد؛ لینک‌های صفحه بلاگ اصلی به مقالات انگلیسی وصل شد.
5. **انیمیشن ملایم** — ظاهرشدن تدریجی بخش‌ها هنگام اسکرول، سایه‌ی هدر هنگام اسکرول، نوار پیشرفت آبی بالا، و افکت hover روی کارت‌ها/دکمه‌ها — بدون تغییر در ظاهر ساده. با `prefers-reduced-motion` غیرفعال می‌شود.

## افزودن مقاله جدید
1. یک فایل HTML در `blog/` (فارسی) و `en/blog/` (انگلیسی) بسازید — از مقالات موجود کپی بگیرید.
2. در `data/posts.json` یک آبجکت جدید به ابتدای آرایه‌ی `posts` اضافه کنید (`status: "published"`).
برای تولید خودکار هفتگی، `scripts/generate_weekly_post.py` از قالب‌های `scripts/templates/` استفاده می‌کند که به تم ساده به‌روزرسانی شده‌اند.
