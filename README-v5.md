# راهنمای نسخه ۵ — بازطراحی خدمت‌محور (سبک planningengineer.net)

## چه چیزی عوض شد؟

### ۱) صفحه اول حالا کاملاً «خدمت‌محور» است — نه «من‌محور»
دقیقاً مثل planningengineer.net که گفتید:
- **عکس و مشخصات شخصی از صفحه اول حذف شد.** دیگر در هیرو و بخش «درباره مشاور» عکسی نیست.
- هیرو جدید: تیتر نتیجه‌محور + دکمه‌های اقدام + عکس هوایی **ایران‌مال به‌صورت بک‌گراند** (با پوشش سرمه‌ای) + سه چیپ اعتبار (۱۵+ سال، ۳۰+ قرارداد ایران‌مال، دکترا).
- ترتیب بخش‌های صفحه اول: هیرو (ایران‌مال) ← نوار متحرک ← آمار ← **۶ کارت خدمت** ← باند اعتبار ایران‌مال ← روش همکاری در ۴ گام ← نمونه پروژه‌ها ← مقالات ← دعوت به تماس.
- انیمیشن‌ها بهتر شد: ورود پله‌ای کارت‌ها (stagger)، شمارنده‌های متحرک، باند عکس‌دار، حالت هاور نرم — همه با همان رنگ‌بندی قبلی خودتان (سرمه‌ای/آبی).

### ۲) معرفی شما فقط در صفحه «درباره من» متمرکز شد
- منوی انگلیسی: `Résumé` → **About** شد (فارسی: **درباره من**). آدرس همان `resume.html` است، چیزی نشسته نیست.
- عکس جدید پروفایل شما (همان که فرستادید، با کیفیت‌به‌ساز ۶۰۰×۶۰۰) در صفحه درباره من + تصویر اشتراک (og-image) به‌روز شد.
- کل رزومه، مدارک، عضویت‌ها و دکمه دانلود CV سر جایش هست.

### ۳) خدمات از ۴ به ۶ سرفصل رسید (صفحه خدمات هم هم‌راستا بازنویسی شد)
۰۱ LPS · ۰۲ برنامه‌ریزی تاکت · ۰۳ کنترل پروژه و Primavera P6 · ۰۴ آنالیز تأخیر و ادعا · ۰۵ آموزش و کارگاه · ۰۶ ارزش‌گذاری و Due Diligence
هر سرویس حالا یک خط «**دریافت شما:**» دارد — مشتری دقیقاً می‌فهمد چه چیزی تحویل می‌گیرد.

### ۴) تصمیم درباره صفحه عربی: یک لندینگ یک‌صفحه‌ای
planningengineer.net (امارات) هم اصلاً نسخه عربی ندارد و بازار GCC انگلیسی کار می‌کند. نگهداری ۵ صفحه عربی با مقالات انگلیسی/فارسی، ناقص به نظر می‌رسید. پس:
- `/ar/` حالا **یک لندینگ کامل و مستقل** است: هیرو + ۶ خدمت + باند ایران‌مال + کارت‌های تماس (تلفن/واتساپ/لینکدین/ایمیل — هر کدام یک خط).
- **این ۴ فایل دیگر وجود ندارد و باید از گیت‌هاب حذف شوند:**
  - `ar/services.html`
  - `ar/resume.html`
  - `ar/contact.html`
  - `ar/blog/index.html` (کل پوشه `ar/blog`)
- sitemap و hreflang هماهنگ شد: نسخه عربی فقط برای صفحه اول اعلام می‌شود.
- اگر بعداً مشتری سعودی جدی آمد، همان لندینگ قابل گسترش است.

## مراحل آپلود روی گیت‌هاب
1. محتوای همین پوشه را روی ریپو `balouchi-moh.github.io` بریزید.
2. **حتماً این‌ها را حذف کنید** (اگر با git کار می‌کنید: `git rm`):
   `ar/services.html` · `ar/resume.html` · `ar/contact.html` · پوشه `ar/blog/`
3. Commit و push کنید. (فایل‌های `en/index|services|resume|contact.html` در بسته نیستند — قبلاً فقط کپی بودند؛ نبودن‌شان مشکلی ندارد.)
4. دو دقیقه بعد `lean-construction.ir` را با Ctrl+Shift+R باز کنید.

## گوگل سرچ کنسول (بعد از آپلود)
1. بخش Sitemaps → `sitemap.xml` را دوباره Submit (حالا ۲۱ URL دارد).
2. URL Inspection برای این ۳ آدرس → Request Indexing:
   `https://lean-construction.ir/` · `https://lean-construction.ir/fa/index.html` · `https://lean-construction.ir/ar/index.html`
3. چند روز بعد در Performance کوئری‌های «lean construction consultant» و «تکت پلنینگ» را چک کنید.
