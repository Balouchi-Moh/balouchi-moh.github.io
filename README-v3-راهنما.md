## ۲) عکس باکیفیت — چطور بفرستید و جاگذاری کنید؟

**مشخصات عکس مناسب:**
- پرترهٔ رسمی (کت‌وشلوار یا پیراهن مرتب)، لبخند حرفه‌ای
- پس‌زمینهٔ ساده (سفید/طوسی/آبی تیره)
- نور از جلو، بدون سایهٔ شدید روی صورت
- حداقل **۱۰۰۰×۱۰۰۰ پیکسل** (ترجیحاً مربع یا عمودی)

**روش جایگزینی در گیت‌هاب (۲ دقیقه):**
1. وارد مخزن سایت شوید → پوشهٔ `images`
2. روی **Add file → Upload files** بزنید
3. عکس جدید را بکشید — **دقت کنید نام فایل دقیقاً `profile.jpg` باشد** (نام عکس قبلی را تغییر ندهید)
4. **Commit changes** بزنید. تمام! سایت خودش عکس جدید را نشان می‌دهد.

اگر عکس را برای من بفرستید، خودم جاگذاری می‌کنم و تصویر اشتراک‌گذاری (OG) را هم با عکس جدید بازسازی می‌کنم.

## ۳) سئو — چه کارهایی انجام شد و چه کارهایی با خودتان است؟

### ✅ کارهای فنی که در همین نسخه انجام شد:
| مورد | توضیح |
|---|---|
| تگ‌های OG و توییتر | وقتی لینک سایت را در لینکدین/واتساپ بفرستید، کارت حرفه‌ای با عکس و عنوان نمایش داده می‌شود (تصویر `og-image.jpg` ساخته شد) |

| مقالات یتیم | دو مقالهٔ LPS که هیچ‌جا لینک نشده بودند، به فهرست مقالات فارسی اضافه شدند |
| قالب مقالات آینده | مقاله‌های جدیدی که می‌سازید، خودکار تگ‌های سئو می‌گیرند |

### 🎯 گام‌هایی که فقط خودتان باید انجام دهید (مهم‌ترین بخش):

**گام ۱ — Google Search Console (۱۵ دقیقه، مهم‌ترین گام):**
1. به [search.google.com/search-console](https://search.google.com/search-console) بروید و با اکانت گوگل وارد شوید
2. یک Property از نوع **URL prefix** بسازید: `https://lean-construction.ir/`
3. برای تأیید مالکیت، روش **HTML file** را انتخاب کنید — فایل `google1c3fe492fcfeaf02.html` قبلاً در سایت آپلود شده؛ اگر گوگل فایل دیگری داد، همان را در مخزن آپلود کنید
4. بعد از تأیید: منوی **Sitemaps** → تایپ کنید `sitemap.xml` → **Submit**
5. از منوی **URL Inspection** بالای صفحه، آدرس‌های زیر را یکی‌یکی وارد و **Request Indexing** بزنید:
   - `https://lean-construction.ir/`
   - `https://lean-construction.ir/services.html`
   - `https://lean-construction.ir/resume.html`
   - `https://lean-construction.ir/blog/index.html`
   - `https://lean-construction.ir/en/blog/takt-planning.html`

**گام ۲ — Bing Webmaster Tools (۵ دقیقه):** به [bing.com/webmasters](https://www.bing.com/webmasters) بروید → گزینهٔ **Import from Google Search Console** — یک‌کلیک است و بازار بین‌المللی را هم پوشش می‌دهد.
